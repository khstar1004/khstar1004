## 🧠 Professional Profile

연세대학교 건설환경공학과를 기반으로 인공지능, 데이터 기반 의사결정, 그리고 실제 환경에서 작동하는 AI 시스템을 연구·개발해온 AI 개발자입니다.  
저는 AI를 단순한 모델이나 데모가 아니라, 문제 정의부터 데이터 파이프라인, 모델링, 에이전트 워크플로우, 서비스 배포까지 연결되는 **End-to-End Intelligence System**으로 구현하는 데 집중합니다.

육군인공지능센터에서 **한국형 팔란티어 개발 프로젝트**에 참여하며, 국방 데이터 융합·분석·시각화·지휘결심 지원을 위한 미션 크리티컬 AI 플랫폼의 실전적 가치를 경험했습니다. 이 과정에서 임무 중심 AI 시스템, 데이터 기반 지휘결심 지원, 복잡한 현장 문제를 해결하는 AI 아키텍처의 중요성을 체감했으며, 관련 기여를 인정받아 **참모총장 표창**을 수상했습니다.

이전에는 연세대학교 **LangAGILAB**에서 AI 연구자로 활동하며 **Embodied Intelligence**, **LLM-based Agent Systems**, **Auto Reinforcement Learning** 관련 연구를 수행했습니다. 최근에는 웹 탐색 에이전트를 위한 Process Reward Model 연구인 **Web-Shepherd: Advancing PRMs for Reinforcing Web Agents**의 공저자로 참여했으며, 해당 논문은 Hugging Face Papers에서 주목받았습니다.

또한 **ShopTalk** 프로젝트를 통해 쇼핑 에이전트 고도화와 소상공인 비즈니스 자동화 플랫폼을 개발하고 있으며, 연세대학교 예창패 1차 선정 이후 **CTO**로 활동하며 **7.5천만 원 투자유치**를 이끌었습니다. 현재는 국방 AI, LLM Agent, Web Automation, XR/Digital Twin, Kubernetes 기반 플랫폼 엔지니어링을 융합해 현실 문제를 해결하는 확장 가능한 AI 시스템을 만드는 것을 지향합니다.
